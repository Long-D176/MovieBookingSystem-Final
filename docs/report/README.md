# Overleaf Report Package

Upload the full contents of this folder to Overleaf:

- `main.tex`
- `assets/logo.png`
- `assets/Diagram.png`
- `assets/evidence/*.png`

In Overleaf, set the compiler to **XeLaTeX**.

Main file:

```text
main.tex
```

The report follows the required five-chapter structure:

1. Overview & System Architecture
2. Infrastructure Provisioning
3. CI/CD Pipeline Design
4. Deployment & Orchestration
5. Monitoring, Observability & Lessons Learned

Before submission, verify that no screenshots expose passwords, private keys, SMTP credentials, or GitHub secrets.
