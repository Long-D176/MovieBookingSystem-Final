# Documentation Directory

This folder contains project documentation, reports, checklists, and demo guidance.

## What is inside

- `report/` - academic or formal project report materials.
- `evidence/` - implementation evidence and supporting records.
- `DEMO_RUNBOOK.md` - step-by-step demo instructions.
- `PRODUCTION_CHECKLIST.md` - production readiness checklist.

## How it works

These documents describe how the system is designed, deployed, tested, and demonstrated. They help the team keep the project consistent and explain the solution to others.

## How to use

1. Read the runbook before demos or presentations.
2. Review the checklist before production deployment.
3. Use the report files when writing or updating project documentation.
4. Store proof and notes inside the evidence folder.

## Notes

- Keep documentation in English unless a different language is explicitly required.
- Update docs whenever the system behavior or deployment process changes.
- Keep evidence files organized by topic or milestone.
